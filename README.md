# Календарь игр Вестмарша

Неофициальная закладка для [vestmarch.noncensored.ru](https://vestmarch.noncensored.ru/games): над списком игр появляется календарь по дням, а игры, на которые вы записаны, подсвечены и показаны первыми. В календарь можно занести свои игры с других площадок и сразу видеть накладки с играми Вестмарша. Ваншот заводится одним окном. Модуль или кампанию заводят один раз (название, мастер, место по умолчанию, описание, картинка с выбором участка), а потом к ним добавляют только сессии: дата, время и, если нужно, другое место и повтор по неделям.

**Установка:** <https://malan-x.github.io/vestmarch-calendar/>

## Как устроено

- `vestmarch-calendar.user.js` — сам скрипт. Работает и как userscript (Tampermonkey, Violentmonkey), и как скрипт, который подгружает закладка.
- `index.html` — страница установки. Закладка на ней короткая: она только подгружает `vestmarch-calendar.user.js` с GitHub Pages, поэтому исправления доходят до всех без переустановки.

Скрипт обращается только к сайту Вестмарша: читает список игр (`/api/backend/games/FetchGameSessions`), текущую сессию (`/api/auth/session`) и записи текущего пользователя (`FetchMyGameSignups`). Это внутренний API сайта, поэтому при его изменениях скрипт может перестать работать.

Свои игры хранятся в `localStorage` сайта Вестмарша под ключом `vmcal.own.v1`, только в этом браузере, и никуда не отправляются. Длительность игр Вестмарша API не отдаёт, для поиска накладок она принята за 4 часа (`VM_GAME_HOURS` в начале скрипта).
