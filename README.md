# Календарь игр Вестмарша

Неофициальная закладка для [vestmarch.noncensored.ru](https://vestmarch.noncensored.ru/games): над списком игр появляется календарь по дням, а игры, на которые вы записаны, подсвечены и показаны первыми. В календарь можно занести свои игры с других площадок и сразу видеть накладки с играми Вестмарша. Ваншот заводится одним окном. Модуль или кампанию заводят один раз (название, мастер, место по умолчанию, описание, картинка с выбором участка), а потом к ним добавляют только сессии: дата, время и, если нужно, другое место и повтор по неделям. Нажав на заголовок дня, можно отметить, что вы заняты (на день или несколько, с заметкой для себя): игры в эти дни будут помечены «⛔ Вы заняты».

**Установка:** <https://malan-x.github.io/vestmarch-calendar/>

На странице «Простой» закладка дописывает в карточки «Проектов Оплота», под кнопки, подсказку для персонажа, выбранного на странице: на сколько процентов проверка лучшим навыком выгоднее или невыгоднее вклада «+1» и раскрывающийся список всех проверок. Цвет — от зелёного (проверка заметно выгоднее) через нейтральный (выгоднее меньше чем на 10%) к оранжевому и красному (невыгодна); кнопка «Проверка» окрашивается тем же цветом, а лучшее из двух действий обводится зелёным. Учтено: успех +2, натуральная 20 — +3, провал — истощение, натуральная 1 — два истощения, снять истощение стоит 2 ОД; текущее истощение уже вычтено из бросков. Модификаторы считает та же функция сайта, что и сама страница, — с владениями, экспертизой, бардом, порядком и бонусами эффектов. Инструменты предлагаются, только если у персонажа есть владение ими, сам инструмент в инвентаре или мультиинструмент.

Там же у каждого проекта есть кнопка «Влить все · N ОД»: после подтверждения она по очереди нажимает родную кнопку «+1 · 1 ОД», пока не кончатся очки (повторное нажатие — «Стоп»). Если сайт не списал очко, вливание останавливается.

## Как устроено

- `vestmarch-calendar.user.js` — сам скрипт. Работает и как userscript (Tampermonkey, Violentmonkey), и как скрипт, который подгружает закладка.
- `index.html` — страница установки. Закладка на ней короткая: она только подгружает `vestmarch-calendar.user.js` с GitHub Pages, поэтому исправления доходят до всех без переустановки.

Скрипт обращается только к сайту Вестмарша: читает список игр (`/api/backend/games/FetchGameSessions`), текущую сессию (`/api/auth/session`) и записи текущего пользователя (`FetchMyGameSignups`). Это внутренний API сайта, поэтому при его изменениях скрипт может перестать работать. Для «Простоя» скрипт дополнительно читает (от вашего входа) ваших персонажей, проекты Оплота, каталог инструментов, а эффекты и инвентарь — только выбранного персонажа; это то же, что загружает сама страница. Расчёт навыков — функция из кода сайта. Сам скрипт ничего не меняет: «Влить все» нажимает кнопки страницы.

Свои игры хранятся в `localStorage` сайта Вестмарша под ключом `vmcal.own.v1`, только в этом браузере, и никуда не отправляются. Длительность игр Вестмарша API не отдаёт, для поиска накладок она принята за 4 часа (`VM_GAME_HOURS` в начале скрипта).
